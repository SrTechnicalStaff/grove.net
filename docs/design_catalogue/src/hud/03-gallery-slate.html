01Header“Gallery” in display type, slate hue — the surface's identity. Facets are quiet text controls; the count is mono metadata, never a headline.
02Masonry mathColumn count comes from the width available: columns balance around a comfortable minimum frame width and never go below it. Gutters are the small step, 8px. Frames set the row rhythm — there is no row grid.
03Identity beneathOne mono line per card — title, kind, date — at reduced ink, under the frame. Never overlaid on the image.
04Newest first, complete edgesInsertion order, top of the wall down. Portrait, landscape, panorama and square all keep their own aspect and their whole frame.

01Two peer panesLeft and Right assignment in the slate host. Peers, not primary and secondary — neither pane outranks the other.
02Independent scrollEach pane keeps its own position. Scrolling one never moves the other.
03Independent filtersGallery is faceted to GIFs; Memories is untouched. Facet state belongs to the pane, not to the host.
04Independent selectionA selection in one pane says nothing about the other. Focus reads through structure and role, never by dimming the neighbour.
05Fewer columns, same frame sizeAt half width the wall drops to one column rather than shrinking frames below the comfortable minimum. Column count changes; the reading size of a frame does not.
