01Enter — line breakThe default key extends the thought. A note is multiline by nature; committing it is never an accident of typing.
02Shift+Enter — save, start nextOne chord commits the Note and returns an empty composer. The hands never leave the keyboard between thoughts.
03Ctrl+Enter — save, then actCommits the Note and surfaces its follow-up actions. Acting on a thought is opt-in, one chord away — never forced.
04Momentum owns the keysEvery chord ends with the composer ready again. Capture is a stream of entries, so the key grammar optimizes the next entry, not the current one's ceremony.

01Edit returns to the composerChoosing Edit on a saved Note moves its full text back into the composer. There is one editing place on this surface, and it is the composer.
02Save updates, never duplicatesSave commits the change to the same Memory. Cancel returns the Note to the feed unchanged. A second copy is never created.

04Explicit exits while editingSave and Cancel are visible; escape cancels only the active edit. Saved Memories are never at risk from dismissal.
