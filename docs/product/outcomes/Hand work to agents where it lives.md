# Hand work to agents where it lives

## Purpose

Make delegation spatial: leave work for an agent on the Grid itself, watch a
draft take shape in its own place, and accept it where it belongs.

## Background

Three feasibility-proven experiences compose into one journey. Task notes:
a placed Note anchored to an agent is an assignment, picked up where it
stands. Staging Layers: an agent drafts its arrangement on a Layer it
created, visible through cross-Layer presence, and acceptance transfers the
work to its destination. Field-sense offers: an agent subscribed to field
records may offer help when a cluster gathers, always as a proposal. All
three ride existing mechanics — anchors, Layer CRUD, transfer, the field
stream — under [[../../decisions/Agent participation contracts]].

## Outcome

> I can leave work for an agent right on the Grid and see its draft take shape in its own place, so delegation feels like leaving a note for a colleague, not filling out a ticket.

## Behavior scenarios

### Leave a task where it belongs

When I place a Note describing what I want and anchor it to an agent, that
agent picks it up from that spot; the Note itself carries the assignment
and its location carries the context.

### Drafts in their own place

When an agent works a larger arrangement, it drafts on its own staging
Layer; I see its presence there from mine and can go watch the draft grow.

### Accept where it lands

When the draft is ready, I review it in place and accept; the arrangement
transfers to the destination Layer as ordinary attributed Content. Decline
retires the staging Layer without residue.

### Offers, never intrusions

When material gathers where an agent has standing, it may offer a tidy-up
or a reading as a waiting proposal — one quiet offer, never an unrequested
change.

## Context

Assignment, staging, transfer, and offers are governed by
[[../../decisions/Agent participation contracts]] (trust, provenance,
cues). Pipelines between agents are the same grammar repeated:
one agent's accepted output region is another's task context.

## Decisions

- A task Note is ordinary Content: editable, movable, removable; unanchoring
  it withdraws the assignment.
- Staging Layers are ordinary Layers, agent-created and visibly owned;
  acceptance uses the transfer contract; decline removes only the staging
  copy.
- Field-sense offers require standing granted at setup and always arrive as
  proposals.

## Non-goals

- A ticket queue, kanban, or separate task database.
- Offers triggered by watching the person (field facts only).
- Autonomous cross-Layer commits outside granted scope.
