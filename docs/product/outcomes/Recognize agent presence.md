# Recognize agent presence

## Purpose

Give agents a visible, honest hand on the field: where each is focused and
whether it is thinking, acting, or waiting — even though agents work in
turns rather than continuous motion.

## Background

A human cursor moves continuously; an agent acts in turns while remaining
"on". Presence must be truthful about that rhythm: a resting mark where the
agent last worked, a thinking state while a turn is underway, a decisive
acting moment when a commit lands, and a waiting state when it needs a
person. Presence is cell-anchored like everything on the Grid, and it must
stay calm — presence is company, not surveillance chrome.

## Outcome

> I can always see where an agent is focused and whether it is thinking, acting, or waiting, so nothing in my field ever changes without a visible hand behind it.

## Behavior scenarios

### A hand, not a ghost

When any change lands from an agent, its presence mark is there — no
Content ever appears or moves without a visible, named source.

### Truthful rhythm

When an agent is between turns, its mark rests quietly where it last
worked; when a turn runs, the mark shows thinking; when a commit lands, the
mark acts on those cells; when it needs me, the mark waits visibly.

### Present across Layers

When an agent works on another Layer, its presence reads through the same
cross-Layer grammar the field uses, so I know who is where without leaving
my Layer.

### Named and consistent

When multiple agents share the field, each keeps one stable identity — name
and accent — everywhere it appears: mark, roster, threads, and attribution.

## Context

Presence marks are cell-anchored view state, never product facts. Accent
assignment must respect the existing hue-role rules — presence may not
impersonate selection, refusal, or field meaning. Exact forms and their
cross-Layer reading remain open in
[[../../discovery/Grove agents and grid multiplayer]].

## Decisions

- Presence is cell-anchored and turn-truthful: resting, thinking, acting,
  waiting — never a fake continuous cursor.
- Every agent action is attributable at the moment it lands and afterward.
- Presence marks are derived view state; they persist nothing and never
  occupy cells.

## Non-goals

- Live pointer trails or human-style cursor mimicry.
- Presence chrome that competes with Content or the field.
- Anonymous or unattributed agent activity of any kind.
