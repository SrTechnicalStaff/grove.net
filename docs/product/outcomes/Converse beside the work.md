# Converse beside the work

## Purpose

Put conversation with agents where teammates put it on shared canvases:
anchored beside the content under discussion, threaded, and owned by the
place rather than a chat window.

## Background

The Information Plane already owns content-attached locality. Conversation
extends it: a thread opens beside selected Content or a region, carries
person and agent turns with stable identities, and can hand its results to
the field — an agreed change becomes an agent task, a good answer can be
kept as Memory. Selection-to-task is the same gesture family: select
content, choose an agent, say what's needed — beside the work, not in a
console.

## Outcome

> I can talk with an agent right beside the content we are discussing, so the conversation stays with the work instead of drifting into a separate window.

## Behavior scenarios

### Threads live at the work

When I start a conversation from selected Content or a region, the thread
opens beside it and stays anchored there; returning to the place returns
the conversation.

### Task from selection

When I select Content and address an agent, my message carries that
selection as shared context; the reply lands in the same thread, and any
resulting work follows the trust posture on the field.

### Both voices, one grammar

When an agent replies, its turns are marked with its identity and read in
the same thread grammar as mine; streaming arrives as a growing message,
not a spinner.

### Keep what matters

When a thread produces something worth keeping, I can promote a message to
Memory with its provenance, or let the thread stay conversational.

## Context

Threads are Information Plane surfaces: local, camera-independent,
dismissed back to focus. Whether threads are durable Memories or
session-transient — and what promotion means precisely — remains open in
[[../../discovery/Grove agents and grid multiplayer]].

## Decisions

- Conversation is anchored locality, never a floating global chat window.
- Selection context travels with the message explicitly; agents never see
  more than the person shared plus their granted reads.
- Thread identities match presence identities everywhere.

## Non-goals

- A general chat client or channels-and-DMs product.
- Voice, huddles, or human-to-human messaging in this slice.
- Threads as a second content store outside the promotion path.
