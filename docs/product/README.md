# Product documentation

Product documentation contains canonical Product Outcome documents and feature
contracts. Each Product Outcome owns one exact Outcome sentence and its
behavior scenarios. Product Outcome titles name the human change plainly; the
board and companion wireframe copy the same sentence.

Use [[../templates/product-outcome|Product Outcome]] for new documents.
