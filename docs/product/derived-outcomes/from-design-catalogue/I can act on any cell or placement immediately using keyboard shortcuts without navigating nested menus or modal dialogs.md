# I can act on any cell or placement immediately using keyboard shortcuts without navigating nested menus or modal dialogs

## Outcome
> I can act on any cell or placement immediately using keyboard shortcuts without navigating nested menus or modal dialogs.

## Behavior Scenarios

### Direct Keyboard Action Execution
Pressing `N` creates a note at the active cursor cell, pressing `2`-`4` switches authored note colors, and pressing `A` toggles an anchor ribbon instantly.
