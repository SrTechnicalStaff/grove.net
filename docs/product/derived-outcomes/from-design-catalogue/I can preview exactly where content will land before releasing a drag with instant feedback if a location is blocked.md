# I can preview exactly where content will land before releasing a drag with instant feedback if a location is blocked

## Outcome
> I can preview exactly where content will land before releasing a drag with instant feedback if a location is blocked.

## Behavior Scenarios

### Placement Ghost & Refusal Signal
Dragging content over empty grid cells renders a ghosted placement footprint; dragging over occupied cells renders a refusal stroke in `--signal-refusal` (`#E2625C`).
