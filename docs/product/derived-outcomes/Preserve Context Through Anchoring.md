# Product Outcome: Preserve Context Through Anchoring

> **Outcome Statement**: 
> "I want to label and associate information based on where it lives and what surrounds it, so I don't lose the original context or have to force everything into artificial folders."

---

## 1. Human Behavior Shift

### Previous Behavior (Status Quo)
In conventional software, users are forced to store notes, documents, and assets inside rigid hierarchical folder trees or tag clouds. When an idea relates to multiple topics, users must either duplicate the file (creating desynchronized copies) or choose a single arbitrary folder, stripping away the surrounding context in which the thought was originally conceived. Re-finding information later requires remembering the exact folder path or keyword tag rather than relying on spatial memory.

### Transformed Behavior
Users capture and label information directly where it occurs relative to surrounding reference materials. Instead of filing items away into isolated folders, users place ideas on a spatial canvas where nearby content provides instant, passive context. Labels ("anchors") attach directly to spatial surroundings, preserving the natural cognitive links of human thought without enforcing pre-baked taxonomy.

---

## 2. Underlying Product Architecture & Primitives

This human behavior shift is made possible by the intersection of three Grove primitives:

- **[Memory](../definitions/Memory.md)**: Stores the underlying semantic record independent of rigid file paths, allowing multiple anchors to attach to a single core thought.
- **[Grid](../definitions/Grid.md)**: Provides the 2D spatial coordinate plane where surrounding content establishes natural cognitive bearing and proximity without folder walls.
- **[Content](../definitions/Content.md)**: Manifests the anchored Memory as visible text or media on the canvas, ensuring surrounding context remains visible at a glance.

---

## 3. Behavioral Verification Scenarios

### Scenario 1: Natural Spatial Labeling
- **Given** a user is reviewing background research and notes on a visual surface,
- **When** they create a new summary label or note beside a cluster of reference materials,
- **Then** the label retains its association with those surrounding items through spatial location rather than requiring assignment to a folder hierarchy.

### Scenario 2: Recalling Context Without Folder Traversal
- **Given** a user returns to a project after several weeks away,
- **When** they look at an anchored note on the workspace canvas,
- **Then** they immediately understand what the note pertains to by observing the neighboring documents and images positioned around it.
