# Review ledgers

The `RCA-*.md` files in this directory are historical audit ledgers. Their
claims and line references describe the tree at the time each review was
written; they are not implementation status markers.

For current truth, use the executable source, the ADR `status`/`verification`
frontmatter, and [`docs/specs/ADR-ROADMAP.md`](../specs/ADR-ROADMAP.md). The
roadmap records verified partial slices and names the remaining gaps instead of
using the former “implemented — awaiting user review” label.
