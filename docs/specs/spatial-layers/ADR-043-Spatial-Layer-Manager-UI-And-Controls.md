# ADR-043: Grid Layer Manager UI and Controls

This duplicate specification is retained as an index entry only. Its former
active/inactive rendering rules are retired. The normative Grid Layer Manager
contract is [the HUD Plane ADR-043](../fluent-design-system/ADR-043-Fluent-Layer-Manager-Overlay.md),
which defines selected Grid Layer command context, full rendering participation,
explicit visibility, and lock refusal.
